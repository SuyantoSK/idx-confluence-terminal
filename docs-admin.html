Bagian I

Bab 1. Overview Sistem & Filosofi Desain

1.1 Visi Sistem: Zero-Dependency Native Architecture

Server dibangun secara murni memanfaatkan pustaka bawaan Node.js (http, https, tls, crypto, fs, url, path). Tidak ada dependensi ke Express framework ataupun Nodemailer. Ini meminimalkan attack surface, meniadakan risiko breaking changes dari package eksternal, dan menjaga penggunaan RAM di bawah 70 MB.

1.2 Topologi Jaringan & Visual Flow Infrastruktur

Akses masuk internet diarahkan melalui Cloudflare DNS/SSL ke domain publik terminal.abusalman.my.id. Trafik diteruskan melalui jaringan virtual mesh ZeroTier menuju host server lokal sebelum dipetakan oleh reverse proxy Nginx ke container internal port 3000.

1.3 Penanganan Real IP Klien

Container mengekspos port internal 3000. Deteksi IP klien untuk proteksi rate limiting menggunakan fallback berjenjang: req.headers['x-forwarded-for'] || req.socket.remoteAddress || 'unknown-ip', memastikan penalti pemblokiran tepat sasaran pada IP penyerang dan bukan IP proxy lokal.

Bab 9. Modul Analitik Khusus (PRO Exclusive Flows)

9.1 Top 20 Net Foreign Flow (Akumulasi vs Distribusi Asing)

Dihitung dengan formula: NetForeign = Direction × (Turnover × (Min(VPA, 3) / 5)). Dikelompokkan menjadi sub-tab: TOP 20 BUY dan TOP 20 SELL.

9.2 Bandarmology Flow & Power Score Calculation (1-100)

Mendeteksi pola bandar bursa:
• BIG ACCUM: VPA $\ge 2.0\text{x}$, FQS $\ge 1.8\text{x}$, Bullish (Power score hingga 99).
• ACCUMULATION: VPA $\ge 1.2\text{x}$, Bullish (Power score hingga 85).
• BIG DISTRIB: VPA $\ge 2.0\text{x}$, Bearish (Power score drop ke 15).
• DISTRIBUTION: VPA $\ge 1.2\text{x}$, Bearish (Power score drop ke 30).

9.3 VPA Spike & Pattern Recognition Scanner

Menyaring pola kuantitatif bursa:
• Absorption Breakout: VPA $\ge 3.0\text{x}$ saat Bullish (Penyerapan resistensi).
• Effort to Rise: VPA $\ge 1.2\text{x}$ saat Bullish.
• High Volume Sell: VPA $\ge 2.0\text{x}$ saat Bearish.

Bab 20. Standard Operating Procedures (SOP) & Runbook

20.1 Deployment, Backup users.json, dan Restart Container

# Backup database:
cp users.json users_backup_$(date +%F).json
# Restart container aplikasi:
sudo docker restart idx_standalone_screener
# Pantau log pengiriman OTP dan aktivitas server:
sudo docker logs -f --tail 20 idx_standalone_screener

20.2 Prosedur Regenerasi Kunci Google App Password

Jika Google mencabut App Password: buka Akun Google Owner → Keamanan → Sandi Aplikasi → Buat sandi 16 digit baru → Perbarui konstanta SMTP_PASS pada web.js → Restart container.

20.3 Penanganan Kendala Jaringan SMTP TLS (Timeout / Auth Error 535)

Pastikan port keluar 465 tidak diblokir oleh firewall ISP atau router NAS lokal. Gunakan mode IP bridge bila container gagal menjangkau smtp.gmail.com.

20.4 Penanganan Yahoo Finance Rate Limit & Skema Fallback Data

Jika Yahoo Finance mengembalikan respons kosong, sistem secara otomatis mempertahankan data terakhir dari memori cache 5 menit agar terminal tidak mengalami error tampilan.

20.5 Prosedur Pemulihan Saat Jaringan Virtual ZeroTier Terputus

Jalankan perintah restart service ZeroTier pada host NAS: sudo systemctl restart zerotier-one dan pastikan status interface berada pada kondisi OK.
